## Guest application setup
The guest application uses Formspree. Create a form at
[Formspree](https://formspree.io/), then set the form's
`data-formspree-endpoint` attribute in `index.html` to its
`https://formspree.io/f/FORM_ID` endpoint. Until a valid endpoint
is configured, the submit button stays disabled and no application
data is sent.
